# 拾语隐私说明（0.1.5 预发布版）

更新日期：2026-11-17。

本文说明 `Mary253j/shiyu-chat` 0.1.5 Android 预发布版的数据处理方式。维护者为 GitHub 账号 [Mary253j](https://github.com/Mary253j)，普通非敏感反馈使用 [仓库 Issues](https://github.com/Mary253j/shiyu-chat/issues)，安全报告方式见 [SECURITY.md](../SECURITY.md)。安全报告入口的可用状态以 SECURITY.md 为准。

0.1.5 采用 GitHub prerelease 分发，不代表应用商店上架或任何实名资质已经完成。GitHub 账号是当前公开的维护者标识，不冒充实名运营主体；未来进入应用商店时需另行补齐真实主体及相应材料。

## 你使用的服务

拾语是独立开发的 DeepSeek API 客户端，不是 DeepSeek 官方应用。你使用自己的 DeepSeek 账户、API Key 和余额。软件功能免费，API 使用费用由你直接向 DeepSeek 支付；可选的“请作者吃个鸡腿🍗”与 API 费用无关。

当前仅面向 Android，支持文字聊天、思考模式、历史导入后的续聊，以及 Flash 模式下的图片与文档附件，尚未提供官方客户端的全部功能。应用没有作者运营的聊天服务器、账户系统或聊天云同步，也不内置广告或遥测分析。附件上传使用 DeepSeek 的远端文件服务，其保留规则与本地聊天记录不同。

## 数据在哪里处理

| 数据 | 原生 Android 中的处理方式 | 什么时候离开设备 |
| --- | --- | --- |
| API Key | 使用操作系统支持的 SecureStore 保存，供请求鉴权使用 | 连接 DeepSeek API 时，经 HTTPS 发送给 DeepSeek；不发送到作者服务器 |
| 聊天正文与思考内容 | 以原生异步 AES-256-GCM 按会话加密保存在本地，索引单独加密；密钥保存在系统安全存储中 | 发送消息时，为完成当前轮对话，应用会把本轮输入及所需的历史上下文发送给 DeepSeek |
| 导入的历史记录 | 你主动选择文件后在本地读取，原始会话 JSON 独立加密保存，日常聊天更新不必重复保存未变的原始数据 | 导入操作本身不向作者上传；继续聊天时，选取的历史上下文会随请求发送给 DeepSeek |
| 图片与文档附件 | 你通过系统选择器主动选择；聊天记录只加密保存文件名、类型、大小、远端 `file_id` 等引用信息，不保存可恢复的附件原件 | 点击发送时，文件原件通过 HTTPS 直接上传到 DeepSeek 官方 Files API；聊天请求引用上传结果 |
| 导出的聊天备份 | 由你主动生成的明文文件 | 保存到你主动选择的文件夹；之后交给其他应用时，由相应应用或服务处理 |
| 应用设置 | 用于当前设备上的界面和功能选择 | 与 API 请求有关的设置，如选择的模型或思考模式，会随请求发送给 DeepSeek |

本地加密用于保护设备上的存储文件，并不是“聊天内容只有你自己能看到”的端到端加密承诺。为了生成回复，DeepSeek 必须处理发送给它的消息；应用运行期间也会在内存中处理明文内容。设备被解锁、越狱、Root 或被恶意软件控制时，不能依赖本地加密提供绝对保护。

SecureStore 在 Android 使用系统 Keystore 支持的加密存储。[Expo SecureStore 说明](https://docs.expo.dev/versions/v58.0.0/sdk/securestore/)

## 与 DeepSeek 的连接

原生应用通过 HTTPS 从手机直接连接 `api.deepseek.com`，不经过作者的 API 中转服务。除请求中由应用提交的内容外，服务提供方还可能获得建立网络连接所必需的信息，例如 IP 地址，并按照其政策处理请求、安全与计费信息。

DeepSeek 对数据的保存、使用、安全审核和删除请求，由其当前适用的服务协议、隐私政策及账户设置决定。拾语没有能力承诺 DeepSeek 不保存请求，也不能替用户删除 DeepSeek 持有的数据。使用前请在 [DeepSeek 开放平台](https://platform.deepseek.com/) 查看相应条款。

历史记录导入不代表官方账户自动同步。上下文默认“自动”，旧版未设置模式的配置也转为自动：在 1M 模型窗口内预留输出与安全空间后，按文本估算容量尽量发送当前会话、当前分支的可用历史文字，并显示截断统计。不会自动拼接其他会话或分支，也不会发送历史思考过程和原始导入 JSON。相较旧版默认最近 40 条的方式，可能发送更多旧消息；你也可以手动选择最近消息模式。附件展开后的 token 数无法预先准确估算，仍可能遇到平台容量限制。继续旧对话时，历史消息可能再次计入 API 输入并产生费用；软件免费不等于 API 免费。

## 附件上传、计费与远端保留

附件使用同一个 DeepSeek API Key，不需要另设账户或向作者购买服务。先选择文件、点击发送时才上传，单纯选择文件不会发给 DeepSeek。请在发送前检查附件是否包含身份信息、私人图片、工作资料或其他不应提交给模型的内容。

系统文件选择器会把选中的文件复制到应用临时缓存，供本次上传使用；这些临时副本不属于 AES-GCM 加密聊天数据库。成功提交聊天、移除草稿、删除对应对话或清除所有本地数据时，应用会尝试清理相应缓存副本，不删除你原来保存的源文件。上传或发送失败时保留草稿以便重试；草稿不会在进程重启后恢复，异常中断或清理失败留下的缓存可能仍需由系统回收。请不要把草稿或缓存当作附件备份。

图片和文档由 DeepSeek 处理。PDF、Word 和 PowerPoint 默认采用图文解析，使用识别出的文字和图片，但不保证每个图表、图形或版式都被完整识别。文档解析成功可能产生独立于聊天生成的费用，具体规则和金额以 DeepSeek 当时的接口说明与账单为准。取消等待、停止生成、回复失败或删除本地记录，都不保证撤销已发生的解析或其他费用，也不表示远端文件已经删除。

**DeepSeek Files API 默认永久保留上传文件。** 本应用不因删除本地会话、清除 Key、卸载或导出备份而自动删除 DeepSeek 上的文件。远端文件的保留、访问和删除受 DeepSeek 当前规则及对应账户权限管理；如需删除，应使用其提供的管理方式。参考 [Files API](https://api-docs.deepseek.com/guides/files_api/)、[文档解析](https://api-docs.deepseek.com/guides/document_parsing/)和[视觉理解](https://api-docs.deepseek.com/guides/vision/)说明。

本地聊天与导出备份只包含附件引用元数据，**不包含附件原件，也不是附件备份**。官方 Files API 不提供下载原件或解析结果的能力。换用其他 DeepSeek 账户、远端删除文件或引用失效后，可能无法继续访问该附件，需要重新选择原文件上传。请单独保留源文件。旧版导入官方 ZIP 时没有迁移的附件原件，不会在升级后自动补回；保留原始 JSON 也不等于已保存其中所引用的附件。若历史消息含可用的 AI 总结，续聊可能带上该总结并注明原件不可用，不能用它替代原文件。

## 本地保存、备份与删除

原生应用在你使用期间保存本地聊天记录，直到你在应用中删除记录、清除相应数据，或设备存储因卸载等操作被系统移除。应用不提供作者托管的备份或找回服务。更换设备、清理数据或系统故障可能造成记录丢失，请按自己的需要导出备份。

**导出的备份是明文，不受应用内 AES-GCM 加密保护。** 文件可能包含私密聊天和思考内容。请保存在自己信任的位置，分享前确认接收方，不要上传到公开仓库、公开网盘或公开的问题反馈中。导出过程不会加入你在应用设置中保存的 API Key 或本地加密密钥；但你写入聊天正文或原始导入文件的敏感内容，可能仍在备份中。重新导入备份不会替你恢复已配置的 API Key。

删除应用内记录不会删除此前导出的文件、原始 ZIP、你通过其他应用发送的副本、DeepSeek 已处理的数据或已上传的 Files API 文件。备份文件与其他副本需要你在对应位置另外管理。删除以选中记录为范围，不对相同文字做全文搜索清除；未选消息、其他分支和原始资料顶层其他字段中的引用或复述不会被自动改写。

你可以删除单条消息、选择多条后批量删除，或删除整个会话，也可以修改或清除已保存的 API Key。单条和批量删除都需确认，批量确认显示所选条数。仅选中的消息被删除，未选中的可见消息保留；删除成功后，被删消息不再参与后续请求，程序会标记缺口以防错误拼接相邻问答。

删除消息也会清理应用持有的原始导入资料。对于能够安全识别的 `messages` 或 `mapping` 结构，清除选中节点的正文、思考、附件等内容，保留必要的节点关系；若无法安全定位和清理，就移除该会话的原始副本并显示提示，其他未选中的可见消息仍保留。因此删除后的新备份可能不再包含完整原始导入 JSON。

正常保存会保留当前版本及一代前序加密记录，用于保护和排查保存问题。删除会话或消息成功保存后，应用取消能够恢复选中记录的前代记录与旧格式副本引用，并尝试清理旧正文和被替换的原始资料文件。删除版本号会持久保存，阻止已排队的旧快照把消息写回；文件清理失败会在后续读取或保存时重试。逻辑删除及清理重试不等于闪存物理安全擦除。

需要清除整个应用的数据时，请使用“清除所有本地数据”操作。应用先删除本地文件，再删除加密密钥和 API Key；如果文件删除失败，会保留密钥以便恢复，而不是宣称已彻底清除。清除本地 API Key 不等于撤销它；如需使其失效，应到 DeepSeek 平台撤销或更换。

0.1.5 发布时沿用 0.1.1 至 0.1.4 的包名和发布签名，支持直接覆盖安装；最终签名核验以 Release 为准。来自 0.1.1 的旧版记录会在首次读取后的保存中迁移为分会话存储，来自 0.1.2 及之后的记录继续使用现有格式。API Key 和加密主密钥继续使用，不要求重新导入历史。建议更新前备份，但正常升级不要卸载应用；旧备份仍可能含之后删掉的内容。

普通迁移过程中，旧密文在新格式成功提交前保留；首次成功提交后通常保留一份最新旧版密文，在下一次产生新版本的成功保存后尝试清理。如果迁移同时提交消息删除，则不保留能够恢复被删内容的旧版引用。读取损坏数据时会报告错误并保留文件，不用空记录覆盖它；保留副本不代表承诺自动找回或无条件支持降级。

应用没有自行实现聊天云同步，并在 Android 配置中关闭系统自动备份。设备厂商的迁移工具或系统行为仍可能不同，不要将系统备份当作本应用的可靠恢复机制。仅仍在使用 0.1.0 通用测试签名的用户，需要先导出并确认备份，再卸载旧版、安装目标新版并导入；卸载导致的数据丢失无法由维护者找回。

## Web 预览的区别

Web 版本只是界面和交互预览。Key、设置与对话仅保存在当前页面内存，刷新、关闭页面或重新打开后丢失，不使用原生 SecureStore，也不承诺原生版的持久化和加密行为。

如果在预览中实际调用 API，消息或主动发送的附件仍会发送给 DeepSeek 并可能产生费用；刷新页面也不会撤销远端请求、删除已上传文件或退还费用。不要在来历不明的演示站点输入真实 Key，不要把 Web 预览作为重要聊天记录的保存位置。

## 权限、外部页面与自愿支持

当前聊天和附件功能不需要应用直接读取相机、麦克风、通讯录或定位数据。导入历史和添加附件使用你通过系统选择器主动选择的文件，导出使用系统文件夹选择器；选中的文件可能包含个人信息，请自行检查内容。

当你主动打开外部网站、系统分享目标或支付工具时，对应服务按照自己的政策处理连接信息和你提交的数据。系统或应用商店本身也可能提供诊断、安装或付款信息，这与应用是否内置遥测 SDK 是不同的处理活动。

Android GitHub 直装版在“请作者吃个鸡腿🍗”页面展示作者提供并授权公开的微信／支付宝二维码原图。两张原图已纳入本版本，并将随公开源码和安装包提供；尚未进行实际付款测试。支付由你在微信／支付宝等对应平台完成，作者可能看到该平台向收款人展示的付款信息。应用不接入支付 SDK、不收集支付密码、不读取支付结果，也不把打开或保存二维码视为付款成功。所有功能始终免费，打赏不解锁任何权益。

## 反馈与后续变更

当前没有开发者账户注册，也没有账号注销流程；你的 DeepSeek 账户由 DeepSeek 管理。应用内记录和 Key 按前述方法清除。

作者不会通过遥测自动获得你的完整聊天、Key 或使用行为。GitHub Issues 是公开渠道，主动提交反馈时请移除 Key、完整聊天、付款凭据、个人身份信息及敏感附件。涉及漏洞或数据泄露，使用 SECURITY.md 中说明的私密渠道；该渠道启用前，不在公开 Issues 中提交敏感细节。

如果以后新增聊天云同步、账户、分析 SDK、语音、支付集成或其他数据处理方式，应先核对并更新隐私说明，说明目的、接收方和选择方式，再发布相应版本。实际处理方式或维护渠道变化时，应同步更新本说明。

## 改动

- Flash 可发送图片、PDF、Word、PowerPoint、表格、文本和电子书等文件，使用现有 Key 直连 DeepSeek 官方 Files API，无需作者服务器或额外 Key。每条最多 4 个附件，单个最多 20 MiB。
- PDF、Word、PowerPoint 默认采用图文解析，可使用识别出的文字和图片；不保证每个图表、图形或版式都被完整识别。
- 上下文默认由最近 40 条改为“自动”，旧设置随之迁移。在 1M 窗口内预留输出与安全空间，按文本估算容量尽量带上当前会话的可用历史，显示截断统计；仍可手动选择最近消息模式。附件展开 token 未知，仍可能遇到平台容量限制。
- 保留孤立用户消息与明确可用的导入中断回复；不发送失败、拒答或不可用的未完成回复。续聊只使用当前分支，不混入其他会话、其他分支、历史思考过程或原始导入 JSON。

## 附件与旧 ZIP 的边界

文件在点击发送并通过本地上下文检查后才上传。解析成功可能另外收费；取消等待不保证撤销已发生的费用或删除远端文件。DeepSeek Files API 默认永久保留文件，删除本地聊天不会自动删除它。

本地记录和导出备份只保存文件名、类型、大小、`file_id` 等引用，不包含附件原件；官方 Files API 也不支持下载原件或解析结果。请保留源文件，换账号、远端删除或引用失效后需要重新选择文件上传。

旧版导入 ZIP 时没有迁移的附件不会自动补回。原会话中可用的文字与 AI 总结可以参与续聊，缺失原件会明确说明；这不等于恢复附件或模型内部记忆，也不保证回答与官方完全一致。

## 安装与升级

目标设备为 **Android 7.0 及以上 ARM64 手机**，版本 `0.1.3`、Android `versionCode 4`。发布时须附 APK、SHA-256 校验值和构建／签名验证记录。

**0.1.1／0.1.2 → 0.1.3：使用同一发布签名，直接覆盖安装，不要卸载。** 最终证书一致性以 Release 验证记录为准。建议先导出备份，但正常升级不需要重新导入 ZIP 或填写 Key。

**仍使用 0.1.0：先备份再重装。** 旧测试签名不同，先导出到应用目录之外并确认可读取，再卸载、安装新版、导入备份并填写 Key；卸载后无法找回未备份的数据。备份为明文，请妥善保管。

本版增加消息单条删除与多选批量删除，并针对键盘遮住输入区、需要先收起才能点击发送的问题调整布局。

## 改动

- 可删除单条消息，也可通过选择按钮进入多选；确认时显示所选条数，仅删除选中消息，未选消息继续显示。
- 删除成功后，被删消息不再进入后续请求；保留删除缺口，避免相邻消息跨缺口被错误配成一轮问答。
- 同步清理原始导入资料中的对应内容。能够识别的结构保留节点关系；无法安全逐条清理时移除该原始副本并提示，其他可见聊天保留。
- 删除保存不保留可恢复已删内容的旧版本引用，拒绝排队的旧快照写回；文件清理失败会在后续读取或保存重试。
- 调整键盘避让与 Android 窗口缩放，键盘弹出时隐藏底部导航、移除底部额外留白，为输入和发送操作留出空间。

## 删除与容量边界

删除只处理选中记录，不对相同内容做全文清除。未选消息、其他分支和原始资料顶层其他字段中的引用或复述仍保留；此前导出的备份、原 ZIP、已经发给 DeepSeek 的内容和官方 Files API 文件不会自动删除。本地逻辑删除不等于手机闪存安全擦除。

继续使用 0.1.4 的 **1 GiB（1024 MiB）** 记录容量上限。这只是放宽容量检查，仍未验证手机能稳定导入 1 GiB；整包读取、解压和解析可能占用数倍内存并导致卡顿或闪退。附件仍为单个最多 20 MiB、每条消息最多 4 个。

面向 **Android 7.0 及以上 ARM64 手机**，版本 `0.1.5`、Android `versionCode 6`。

本版 APK 的独立发布签名已核验，与 0.1.1 至 0.1.4 一致，可直接覆盖安装，**不要卸载**。建议更新前保留备份，但正常升级不需要重新导入历史或填写 Key。旧备份仍可能包含后来删除的消息，需自行妥善保管。

本版针对官方 DeepSeek ZIP 导入时的内存不足错误修改读取与合并流程。此前约 49.5 MiB 的 ZIP 会被一次读入原生内存；现在分块读取、逐会话解析，避免该整包分配。

核心检查、Web 导出、浏览器 UI 测试及正式 APK 构建与签名核验均已完成。

## 改动

- Android 使用异步文件句柄读取，单次最多 64 KiB；Web 预览也只读取对应文件切片。
- 先验证 ZIP 目录和文件头，再逐段解析会话；附件分块解压和校验后丢弃，不留整份附件字节。路径、大小、CRC、索引及条目数量校验继续保留。
- 确认合并时逐会话检查格式与总容量，不再为检查而将旧记录和新记录整库序列化、再解析一遍。
- 读取、校验、整理和保存显示进度；内存不足时显示中文说明。
- 预览或合并校验失败不修改现有记录。重复来源仍跳过，已有空对话不会被自动覆盖；接受导入后如保存失败，保留当前页面并提示重试保存。
- 保留上一版的单条／多选删除、键盘避让、附件和续聊功能。

## 内存与数据边界

继续保留 **1 GiB（1024 MiB）** 的输入、ZIP 解压总量和备份容量上限，单附件上传仍最多 20 MiB、每条消息最多 4 个。64 KiB 是一次读取的大小，不代表整个导入只占用这些内存，也不保证手机能稳定处理任意 1 GiB 文件。

现有会话和导入后的原始资料仍保存在内存，单段特别大的会话仍需完整解析。纯 JSON 虽然分块读取，仍组装全文后解析；实际导出备份仍会生成整库 JSON，以上场景仍可能内存不足。本版未改变数据库格式，也不自动恢复旧 ZIP 中的图片／文件原件。

## 安装与升级

面向 **Android 7.0 及以上 ARM64 手机**，版本 `0.1.6`、Android `versionCode 7`。

本版 APK 已核验与 0.1.1 至 0.1.5 使用同一独立发布签名，可直接覆盖安装，**不要卸载**，正常升级不需要重新导入历史或填写 Key。

仍使用 0.1.0 的用户因旧测试签名不同，应先导出并确认备份可读取，再卸载旧版、安装新版、导入备份并填写 Key。卸载后无法恢复未备份数据。导出的备份是明文，仍可能包含后来删除的消息。

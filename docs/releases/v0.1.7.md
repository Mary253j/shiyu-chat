本版修复 AI 回复正文中反复显示 `\hspace{0cm}` 等零宽度排版指令的问题。已有导入对话升级后自动使用新的显示方式，无需重新导入。

## 改动与范围

- 仅在助手正文 Markdown 显示时识别零值 `cm`／`pt` 的 `\hspace`，兼容带星号、零小数与空白的形式。例如 `今\hspace{0cm}天天气很好。` 显示为“今天天气很好。”。
- 代码区段、显式转义的字面示例、Markdown 链接地址和裸 HTTP(S) 地址保留；非零间距与其他指令不作该处理。本版不提供完整 TeX 公式渲染。
- 用户原文、思考纯文本、复制、保存、备份及 API 上下文仍保留原始文字，未改写已有消息或导入原始资料。
- 导入与存储不变，保留 0.1.6 的分块 ZIP 读取，以及消息删除、附件、续聊和键盘避让。

## 安装与升级

面向 **Android 7.0 及以上 ARM64 手机**，版本 `0.1.7`、Android `versionCode 8`。

本版 APK 已核验与 0.1.1 至 0.1.6 使用同一独立发布签名，可直接覆盖安装，**不要卸载**，无需重新导入聊天记录或填写 Key。

仍使用 0.1.0 的用户因旧测试签名不同，应先导出并确认备份可读取，再卸载旧版、安装新版、导入备份并填写 Key。卸载会移除未备份的数据；导出的备份为明文。

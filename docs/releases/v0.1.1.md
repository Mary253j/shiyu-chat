拾语首次 GitHub 预发布版：让 Android 用户使用自己的 DeepSeek API Key，并导入已有聊天继续文字对话。软件采用 MIT 许可证，全部功能免费；API 费用直接向 DeepSeek 支付。

## 本版内容

- 文字流式回答、思考模式、停止生成和失败重试。
- 导入 DeepSeek ZIP v3、支持的旧版 JSON 或拾语备份；预览后合并，原有记录不被直接覆盖。
- 本地 AES-256-GCM 加密聊天记录，系统安全存储保存 Key；无作者聊天服务器、共用 Key、广告或遥测。
- “请作者吃个鸡腿🍗”页面加入作者提供的微信／支付宝二维码原图，可切换查看。打赏完全自愿，不解锁功能，也不给 DeepSeek 账户充值。
- 使用本项目独立保管的发布签名，替代 0.1.0 的通用测试签名。

## 安装与升级

仅提供 **Android 7.0 及以上 ARM64** APK。下载本页 Assets 中的 `.apk`，核对随附校验信息后安装；应用自带代码，不需要开发电脑或开发服务器。

**已安装 0.1.0 的用户不能直接覆盖升级。** 请先在旧版导出备份，保存到应用目录之外并确认文件可读取，然后卸载旧版、安装 0.1.1、导入备份并重新填写自己的 API Key。卸载会删除本地记录，未备份的数据无法找回。导出备份是明文，请妥善保管。

## 预发布边界

尚未完成 Android 真机、真实 API Key、真实用户导出文件及实际微信／支付宝付款测试。构建、签名校验和模拟测试不能替代上述验证；付款前请自行核对支付平台显示的收款人。

当前聚焦文字续聊，尚不支持官方客户端的全部功能；图片／文档原件和联网工具上下文不参与续聊，请保留官方原始导出文件。没有 iOS 安装包，也未上架应用商店。

普通问题可在仓库 Issues 提交，勿附 API Key、完整聊天备份或付款凭据；敏感漏洞按仓库 SECURITY.md 中的私密报告说明处理。
